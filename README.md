# twindowclean.com

Static website for Tony's Window Cleaning, Hesperia, California, served by GitHub Pages from this
repository. Every `.html` file in the root is a live page.

| Path | What it is |
| --- | --- |
| `*.html` | The pages |
| `style.css`, `main.js` | Shared stylesheet and script |
| `assets/` | Fonts, photos, social cards, the quote tool and its 3D files |
| `sitemap.xml`, `robots.txt`, `CNAME` | Search and hosting settings |

This repository is public. Never commit customer names, addresses, phone numbers or email addresses,
business records, or any credentials.
